# פרויקט מיכון דיווח כמויות ארוחות למדור מזון

## תיאור הפרויקט
מערכת למיכון ואוטומציה של תהליך איסוף, בקרה, דיווח וניתוח כמויות ארוחות עבור מדור מזון.

## מטרות עיקריות
1. **קליטת דיווחים וממשק משתמש**: הזנה קלה, מהירה ומדויקת של כמויות ארוחות לפי יחידות/בסיסים/ארוחות (בוקר, צהריים, ערב).
2. **בקרת איכות ואיתור חריגות**: בדיקות תקינות אוטומטיות, איתור פערים בין כמויות מוזמנות לצריכה בפועל, והתראות על חריגות.
3. **הפקת דוחות וניתוחים**: יצירת דוחות תקופתיים מותאמים, ייצוא ל-Excel/PDF ודשבורד מגמות וניתוח עלויות.
4. **ייעול תהליכי התחשבנות**: חישוב אוטומטי של תשלומים מול ספקי הסעדה ומעקב תקציבי.

## מבנה התיקיות
- `docs/` - מסמכי אפיון, דרישות ותרשימי תהליך
- `src/` - קוד מקור של המערכת (ממשק משתמש / צד שרת / לוגיקה עסקית)
- `data/` - קבצי נתונים, דוגמאות ותבניות אקסל
